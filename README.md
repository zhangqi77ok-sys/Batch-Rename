# 批量重命名工具 (Batch Rename)

只重命名文件/文件夹的**名字**，不修改文件内容。支持选目录、拖拽（树形展示）、5 种重命名模式、实时预览、冲突跳过、一键撤销。上万文件不卡界面。

## 直接运行（开发调试）
```bash
pip install -r requirements.txt
python batch_rename.py
```
> 未装 `tkinterdnd2` 也能跑，只是拖拽不可用，改用界面上的「选择目录 / 选择文件」按钮。

## 打包成 exe（双击运行）
```bash
build.bat
```
产物：`dist\BatchRename.exe`，双击即用，无需 Python 环境。

## 使用步骤
1. **选择或拖入** 文件/文件夹（可多个混合）。输入区是树形结构，目录默认折叠，点箭头懒加载展开。**右键某个根项可单独移除**。
2. 设 **公共选项**（作用于所有模式）：
   - **作用范围**：`全部` / `只文件` / `只文件夹` / `子文件夹`（嵌套目录，不含根直接子项）/ `文件夹下的文件`（嵌套目录里的文件）
   - **递归子层**：勾选进入所有层级；不勾只处理直接子项
   - **过滤**：填通配符（如 `*.png`）只处理匹配项，空则全部
3. 选一个 **模式标签页**（同一时刻只用一种）：
   - **查找替换**：关键词或正则（正则支持 `\1` `\2` 反向引用），可勾「区分大小写」。默认对整个文件名替换（含扩展名，所以删/改后缀如 `.sample`→空 直接生效）；只想改主名、不动扩展名时勾「保留扩展名不动」
   - **序号**：起始值 + 步长 + 补零位数 + 样式（数字 / 小写字母 a,b,c / 大写字母 A,B,C）；可勾「用父文件夹名作前缀」（父目录 `1` 里的文件 → `1-001`、`1-002`）；前缀/后缀/位置（原名前/后/替换原名）。**按父文件夹分组、组内自然排序独立编号**（`file2` 排在 `file10` 前）
   - **大小写**：全大写 / 全小写 / 首字母大写 / 每词首字母大写（文件默认保留扩展名）
   - **删除/插入**：删除第 N~M 个字符（1 起，0=不删）；在位置 P 插入文本（0 起，空=不插）
   - **统一扩展名**：把文件扩展名统一成指定值（如 `jpg`，`.jpeg/.JPG` 全变 `.jpg`）
   > 每个模式参数区下方有**实时示例**（如 `sample.jpg → sample_001.jpg`），不用选文件就能看规则效果。
4. **实时预览**（默认开）：改任意参数自动刷新 `旧名 → 新名 → 状态` 对照表（防抖 300ms）。也可点「刷新预览」手动触发。**双击某行可手动编辑该项新名**做个别微调。
   - 绿=将重命名，灰=无变化，红=冲突/重复跳过（不覆盖已有文件）
   - **只看会改的**：勾选后只显示会改动的行，过滤掉无变化/跳过项，一眼聚焦。
   - **搜索框**：按关键词匹配原名或新名，大表里快速定位。
5. 点 **执行** 落盘。**结果保留在表中并标 ✓ 已改（绿）/ ✗ 失败**，看得见成果。改错了点 **撤销上一次** 恢复，支持**多级撤销**（最多回退 20 批）。
6. 窗口大小、上次用的模式和常用选项会自动记住，下次打开恢复。

## 性能
- 收集 + 计算在后台线程跑，界面不冻结；计算期间「执行」按钮禁用，显示「计算中…」。
- 预览表分批渲染，超过 2000 行只显示前 2000（执行仍按全量跑）。
- 5000 文件收集 + 计算约 0.9s。

## 安全说明
- 目标名与已存在文件冲突时**跳过并提示**，绝不覆盖。
- 文件夹重命名按叶子优先（从深到浅）执行，子项路径不会丢失。
- 序号按父目录分组独立编号，不会跨目录混乱。
- 同目录交换/循环改名（如 `a↔b`）用临时名破环，不会互相覆盖。
- 撤销记录存于 `~/.batch_rename_undo.json`（多级栈，最多 20 批）；窗口/设置存于 `~/.batch_rename_config.json`。
